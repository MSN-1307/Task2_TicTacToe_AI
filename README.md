## 🧠 How the AI Works

The AI uses the **Minimax Algorithm with Alpha-Beta Pruning**:

- **Minimax** → AI simulates every possible future move and picks the best one
- **Alpha-Beta Pruning** → Skips branches that won't affect the result, making AI faster
- On **Hard mode** → AI is completely unbeatable
- On **Medium mode** → AI is 50% smart, 50% random
- On **Easy mode** → AI makes purely random moves
